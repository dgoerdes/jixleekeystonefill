# Jixlee Keystone Fill

Shows Mythic+ keystones of all party members and auto-fills the Group Finder when one keystone is clicked.

## How it works:

Simply type `/jkf` to show all available keystones in your group click on the one you like to play and the group finder window will be opened and pre filled.

## Options:

Use `/jkf options` to open the settings to set default values for: playstyle, min. mythic+ rating and min. item level requirements.

## Why can't it fill in the Title or Descritpion?

Unfortunately those fields are protected by Blizzards API so addons cannot write to them. The same ist true for the Voice Chat field.
